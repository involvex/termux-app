InVxTermux is an unofficial fork of Termux: an Android terminal and Linux environment, extended for phone + PC development.

* Stay in the terminal — git, Bun, and builds in-session
* Default project cwd ~/repos (executable)
* Bundled Android Bun with path redirector for apt/SSH
* In-app Localhost Preview (scan ports, Copy LAN)
* Optional OpenCode AI helper (td-ai) in Preview
* Hacker theme (matrix green on black)

Based on Termux (GPLv3). Not affiliated with the Termux maintainers. Install packages with pkg/apt from the Termux package repositories. Prefer projects under ~/repos — shared storage is often noexec.

Docs: https://involvex.github.io/termux-app/
Upstream Termux: https://termux.dev · https://wiki.termux.com
